### 🚀 Обо мне
Я — Android-энтузиаст, который верит, что софт должен быть быстрым, приватным и визуально безупречным. 
Я не просто пишу код — я создаю инструменты, которые меняют пользовательский опыт. 

### ⚡ Текущий фокус: Nexus Browser
*Браузер, в котором дизайн Material 3 встречается с мощью нативного WebView.*
- 🎨 **UI:** Jetpack Compose, Material Design 3.
- 🛡 **Security:** Нативная блокировка рекламы и трекеров.
- 🚀 **Performance:** Легкий код, отсутствие лишних зависимостей.
